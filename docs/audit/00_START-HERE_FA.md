## نکتهٔ مسیرها

در متن گزارش‌ها، ارجاع‌هایی مثل `arshnaz-audit/code-bugs.md` دیده می‌شود؛ آن‌ها پوشهٔ کاریِ ممیزی در بیرون مخزن بودند. **نسخهٔ داخل مخزن همان‌ها همین پوشهٔ `docs/audit/` است.** ارجاع‌های `frontend/...`، `api/...`، `firebase.rules` و مانند آن نسبت به ریشهٔ مخزن‌اند و دست‌نخورده معتبرند.

## وضعیت پایه (پیش از شروع کار تو)

- `npm run typecheck` → exit 0 · `npm run lint` → ۰ خطا / ۱۲۴ هشدار
- `npm run test:api` → ۸ فایل، ۸۵ تست، همه سبز
- `npm test` → ۲۲۶ فایل تست؛ پس از واقعی‌کردن تایم‌اوت‌ها (`frontend/vitest.config.ts` و تایم‌اوت‌های درون‌تستی `KnowledgeMindMapView.test.tsx`) هیچ شکست شناخته‌شده‌ای باقی نمانده است
- `npx vite build` → موفق، `precache 206 entries (7661.09 KiB)` (پیش‌تر ۲۱۸ فایل / ۲۰.۵MB)
