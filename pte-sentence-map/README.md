# PTE Sentence Map

این پروژه از مخزن `hamedharami-hub/pte-sentence-map` به‌صورت یک زیرپروژهٔ مستقل در مخزن Arshiam وارد شده است.

برای اجرا:

```bash
cd pte-sentence-map
npm install
npm run dev
```

پروژهٔ اصلی Arshiam در ریشهٔ مخزن باقی می‌ماند و با دستورهای تعریف‌شده در `package.json` ریشه اجرا می‌شود.
