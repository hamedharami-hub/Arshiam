# وضعیت ادغام و انتشار Mind

تاریخ: ۲۰۲۶-۱۰-۱۵. مبنا: `a7c5ed0`، شاخهٔ `main`. وضعیت: تأیید نرم‌افزاری کاندید انتشار موفق؛ انتشار Git جدا از تأیید deployment است.

این گزارش تحویل اصلاحات قابل‌آزمون نرم‌افزاری در همهٔ بسته‌های M00–M10 است، **نه گواهی تکمیل همهٔ معیارهای برنامه**. نقشهٔ کلی محصول نیز بسته نشده است. دادهٔ آزمون ساختگی است؛ آزمون mock مدرک اثربخشی، مجوز ترجمه، سرویس زنده یا رفتار دستگاه نیست.

## نگهداری، حریم خصوصی و rollback

- دادهٔ جلسه و پیش‌نویس/بازخورد جدید **محلی و بدون رمزنگاری** است، نه همگام‌سازی ابری. account scope مجوز یا رمزنگاری نیست.
- `DraftPrivacy` حالت موقت را برای تغییرات بعدی ارائه می‌کند؛ نسخه‌های قبلی را حذف نمی‌کند. ذخیرهٔ صریح در حساب/تبدیل اقدام، عمل جداست. خاموش‌کردن حالت موقت، حفظ همان نسخه را درخواست می‌کند.
- بخش «داده‌های Mind روی این دستگاه» پشتیبان خصوصی کامل، import همان مالک، نسخهٔ تعارض قابل دانلود، مهاجرت اختیاری نوشتهٔ قدیمی و حذف تأییدشدهٔ همان حساب را ارائه می‌کند. این فایل حاوی نوشتهٔ حساس است؛ متنش به AI یا telemetry فرستاده نمی‌شود.
- import افزایشی است و نسخهٔ باز را خودکار جایگزین نمی‌کند؛ شکست پس از چند نوشتن، موفقیت کامل گزارش نمی‌شود. تکرار import امن است. حذف cloud/task/note/habit از این کنترل انجام نمی‌شود. خروج حساب به‌تنهایی دادهٔ دستگاه را پاک نمی‌کند.
- schema/keyهای نسخهٔ اول حذف نشده‌اند؛ برگشت رابط، رکوردهای جدید را نگه می‌دارد، ولی رابط قدیمی ممکن است آن‌ها را نمایش ندهد. migration اصل legacy را دست‌نخورده می‌گذارد. rollback استقرار عملاً آزموده نشده است.
- collection جدید Firestore یا دسترسی عامل خارجی اضافه نشده است. قواعد موجود owner-scoped برای artifactهای موجود بررسی ایستا شده‌اند؛ این شاهد emulator نیست.

## شواهد اجرای جاری

- `npm run build`: موفق، exit 0؛ TypeScript نیز موفق. هشدارهای chunk بزرگ و mixed static/dynamic import باقی‌اند.
- API: ۸ فایل / ۹۰ تست، exit 0.
- static rules: ۱ فایل / ۳ تست، exit 0. Firebase CLI و Java در محیط قابل یافتن نبودند؛ **emulator اجرا نشده است**.
- آخرین اجرای هدفمند دامنهٔ Mind: ۲۶ فایل / ۲۳۵ تست، exit 0. سازگاری clinical/canonical writes: ۲ فایل / ۱۰ تست، exit 0.
- اجرای کامل اول (یک worker) هنگام تغییر فایل‌ها پایان یافت: ۳۳۶ فایل موفق، ۵ فایل ناموفق / ۱۳ تست ناموفق، exit 1؛ این اجرا کاندید انتشار ثابت نبود. شکست‌ها شامل قرارداد تست قدیمی برای نام دکمه/guard ذخیره/router/mock تراکنش و فایل‌های همزمان در حال اصلاح بودند؛ موارد با اجرای هدفمند بازآزمایی شدند.
- اجرای کامل تازهٔ کد اصلاح‌شده: **۳۴۲ فایل / ۲۳۷۹ تست موفق، exit 0**؛ `node node_modules/vitest/vitest.mjs run --maxWorkers=2 --minWorkers=2`، مدت ۷۵۳٫۷۵ ثانیه. خروجی مستقیم و exit code مستقل در `C:\Users\hamed\AppData\Local\Temp\opencode\mind-final-full.stdout.log`، `.stderr.log` و `.exitcode.txt` حفظ شده است. در این اجرا فقط دو فایل تستِ قرارداد قدیمی اصلاح شدند؛ کد برنامه تغییر نکرد.
- بازبینی مستقل پیش از انتشار چهار ایراد حریم خصوصی/بازیابی یافت: فیلد خراب داخل envelope معتبر، account autosave در مسیر local Needs، پاسخ دیرهنگام بعد از فعال‌کردن حالت موقت و پیش‌نویس مستقل MethodCard. اعتبارسنجی شکل editor و محدودهٔ Date، حذف autosave و الزام دکمهٔ حساب، بررسی ref فعلی پیش از شروع صف و وراثت حالت موقت اصلاح شدند؛ رگرسیون‌های تازه برای import خراب و حالت موقت اضافه شدند. تغییر view منبع ABC نیز از mode ذخیره‌شده مستقل شد.
- مرورگر محلی `/app/mind` به `/auth?next=...` هدایت شد؛ guard مسیر مشاهده شد، نه هندسه/کاربردپذیری صفحهٔ Mind داخل حساب. بدون جعل login یا استفاده از کلید واقعی ادامه داده نشد.

## مواردی که انتشار ادعا نمی‌کند

صفر باگ، تکمیل کل roadmap، اعتبار پزشکی، اعتبار تمام ترجمه‌ها، دسترسی زندهٔ مدل/عامل خارجی به برنامهٔ کاربر، همگام‌سازی چنددستگاهی جلسات جدید، حذف سراسری همهٔ نسخه‌های دستگاه‌ها و موفقیت استقرار production ادعا نمی‌شوند.
